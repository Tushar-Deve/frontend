# Test Marks Entry and Viewer System

A simple web-based application developed to manage and view student test marks efficiently. This project allows marks entry, storage, and viewing through a clean user interface.

---

## Features

- Student marks entry system
- View entered marks
- Responsive user interface
- Simple and easy-to-use design
- Real-time data display
- Organized marks management

---

## Technologies Used

### Frontend
- React.js

### Backend
- Node.js
- Express.js

### Database
- MySQL/PostgreSQL

---

## Project Modules

### 1. Marks Entry
Teachers or users can enter:
- Student Name
- Roll Number
- Subject
- Marks

### 2. Marks Viewer
Displays:
- Student details
- Subject-wise marks
- Stored records from database
